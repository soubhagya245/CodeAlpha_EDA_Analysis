# CodeAlpha_EDA_Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The objective is to understand sales patterns, profit distribution, category performance, and regional performance.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The project uses the Sample Superstore retail sales dataset.

## Data Cleaning

- Checked missing values.
- Identified duplicate records.
- Removed 17 duplicate records.
- Final dataset contains 9,977 rows and 13 columns.

## Analysis Performed

- Statistical analysis of sales and profit.
- Category-wise sales and profit analysis.
- Region-wise sales analysis.
- Sub-category analysis.
- Sales distribution analysis.

## Key Findings

- Total sales: approximately 2.30 million.
- Total profit: approximately 286,241.
- Technology generated the highest sales and profit.
- West recorded the highest regional sales.
- South recorded the lowest regional sales.

## Visualizations

Four visualizations were created:

1. Category-wise Sales
2. Region-wise Sales
3. Category-wise Profit
4. Sales Distribution

## Project Outcome

This project demonstrates how Python libraries can be used to clean, analyze, and visualize retail sales data to identify useful business insights.
